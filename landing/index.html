01 · 功能

刷题需要的一切，一个不少

  1. 题库管理全生命周期

    JSON 导入导出，多题库同步导入，部分失败不影响其他。已导入的题库支持逐题增删改、按题型和章节筛选。内置示例 JSON，格式一看就懂。

  2. 答题练习模式任选

    顺序或随机模式，题号侧边栏快速跳转。自定义题目数量，按题型筛选（单选/多选/填空/判断）。单题视图或整卷预览，多题库组合练习，支持提前交卷。

  3. 背题模式快速过完

    直接展示题目与答案，逐题标记"记住了"或"待复习"。支持按章节精确筛选、只看待复习题目。适合考前突击或首次熟悉题库内容，效率远高于逐题作答。

  4. 计时系统节奏自控

    两种计时方案：单题倒计时为每道题设置时间压力，整卷计时记录总用时但不限时作答。倒计时少于 10 秒自动警示。

  5. 错题本自动收集

    答错的题目自动进入错题本，按题库分组去重。随时回顾错误，针对性补强薄弱环节。支持从错题本直接进入背题模式。

  6. 练习历史可回溯

    每次练习自动存档，分页列表清晰呈现。点击即可查看逐题回顾——你的答案、正确答案、解析，全部可查。方便追踪进步轨迹。

  7. 数据总览一目了然

    注册后进入仪表盘，总题库数、总题数、练习次数、平均正确率一览无余。最近练习记录展示进步趋势，学习节奏尽在掌握。

02 · 设计原则

为专注学习而设计

  1. 01
    学习为王 功能全部聚焦刷题场景。没有社交动态，没有广告推送，没有冗余功能干扰注意力。
  2. 02
    即时反馈 提交答案的瞬间就知道对错。单选、多选、填空、判断，每题都有解析。不把疑问留到下一题。
  3. 03
    数据属于你 自部署方案，数据库文件就在你服务器上。没有云同步、没有第三方存储、没有账号体系之外的追踪。
  4. 04
    轻量启动 Python + SQLite 的组合，无需安装外部数据库。pip install + uvicorn 两步启动，或者一行 docker compose up -d 完成部署。

04 · 常见问题

你想问的，这里都有

这个平台和商业化刷题 App 有什么区别？
刷题在线是自部署的开源工具，数据存在你自己的服务器上。商业 App 通常走订阅制、数据上云、附带社交和广告功能。这里什么都没有——只有题目和你。
需要联网才能用吗？
部署后完全离线可用。浏览器和服务器在同一台机器上即可运行。适合机房考试、离线学习等场景。
数据安全吗？
数据库是本地 SQLite 文件，没有外部请求发送，没有用户数据离开你的服务器。JWT 认证保护接口访问。
如何导入自己的题库？
按指定 JSON 格式准备题库文件，在题库管理页面点击"导入"上传即可。支持单选题、多选题、填空题、判断题四类题型。页面提供示例 JSON 下载，对照格式填写即可。
支持哪些题型？
目前支持单选题（四选一）、多选题、填空题（文本输入）、判断题（对/错）。每种题型都有独立的计时配置和批改逻辑。
需要什么技术背景才能部署？
会打开终端就够了。有 Python 环境就 pip install -r requirements.txt && uvicorn main:app，有 Docker 就 docker compose up -d。两种方式都已在 README 中写明步骤。
