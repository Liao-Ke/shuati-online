# PRD：刷题在线

## 1. 产品概述

**产品定位**：面向个人的轻量级 Web 刷题平台，支持题库管理、答题练习、自动批改和背题记忆。

**一句话描述**：像 Anki + 在线考试的轻量结合体——导入你的题库，刷就完了。

**目标用户**：个人备考者（考研、公考、资格认证、程序员刷题）。

**非目标**：多人协作、班级管理、在线考试监考、付费订阅。

---

## 2. 用户故事

### 典型使用路径

```
用户注册/登录
  → 导入题库（JSON）
    → 答题设置（选题库、选模式、选题型、选题数、选计时）
      → 逐题作答（选择/填空/判断）
        → 提交后即时反馈（正确/错误 + 解析）
          → 全部答完 → 结果页（正确率、用时、逐题回顾）
            → 错题本自动收录
            → 背题模式（不答题，逐题标记掌握状态）
```

| ID | 角色 | 故事 |
|----|------|------|

| US-02 | 用户 | 我可以登录，系统签发 Token 维持 7 天会话 |
| US-03 | 用户 | 我可以导入 JSON 格式的题库，一次一个或多个 |

## 3. 功能需求

### P0 — 核心答题闭环

| 功能 | 说明 |
|------|------|
| 用户注册/登录 | 用户名+密码，JWT 认证 |
| 题库导入 | 单文件 JSON 导入，支持 choice/fill/judge 三种题型 |
| 题库管理 | 列表、详情（分章节）、删除 |
| 顺序答题 | 按题库排序依次出题 |
| 答案提交与批改 | 即时判断对错，记录答案 |
| 答题结果 | 正确率、用时、逐题回顾 |

### P1 — 答题体验增强

| 功能 | 说明 |
|------|------|
| 随机出题 | 打乱题目顺序（seed 固定，同组数据一致） |
| 多题库组合 | 一次选择多个题库的题目混在一起刷 |
| 题型筛选 | 只做选择题/只做填空题等 |
| 自定义题数 | 从题库中随机抽取子集 |
| 单题计时 | 每道题倒计时，超时自动提交 |
| 整卷计时 | 不限单题时间，记录总用时 |
| 答题进度 | 题号侧边栏，显示正确/错误/未答 |
| 题号导航 | 点击跳转到指定题目 |

### P2 — 学习辅助

| 功能 | 说明 |
|------|------|
| 错题本 | 自动收集答错题目，按题库分组，每题去重 |
| 练习历史 | 分页查看历史记录，点击查看详情 |
| 仪表盘 | 展示总题库数、总题数、练习次数、平均正确率 |
| 背题模式 | 设置筛选条件，一次展示全部题目，逐题标记 known/reviewing |

## 4. 数据需求

### 核心实体

| 实体 | 关键属性 | 说明 |
|------|----------|------|
| User | username, password_hash | 单用户无角色 |
| QuestionBank | title, description | 属于一个用户 |
| Question | type, chapter, content, options, answer, analysis | 属于一个题库 |
| ExamRecord | bank_ids, mode, status, timer_mode | 一次答题会话 |
| AnswerRecord | user_answer, is_correct, time_spent | 每道题的答题记录 |
| ReviewRecord | status (known/reviewing) | 背题掌握标记 |

### JSON 序列化约定

| 字段 | 存储形式 | 示例 |
|------|----------|------|
| bank_ids | JSON 数组字符串 | `"[1,2,3]"` |
| question_ids | JSON 数组字符串或 null | `"[4,7,12]"` |
| question.options | JSON 数组字符串或 null | `'["A. 1","B. 2","C. 3"]'` |
| question.answer | 普通字符串或 JSON 数组字符串 | `"B"` / `'["造纸术","印刷术"]'` |
| user_answer | 普通字符串或 JSON 数组字符串 | `"B"` / `'["造纸术","印刷术"]'` |

## 5. 非功能需求

| 需求 | 说明 |
|------|------|
| 响应式 | 适配桌面和手机端，Bootstrap 5 断点 |
| 无迁移 | 启动时 ORM 自动建表，不引入迁移框架 |
| 单文件数据库 | SQLite，个人使用无需外部数据库 |
| Docker 可部署 | 单容器，端口 8000 |
| 启动速度 | 无外部服务依赖，秒级启动 |
| 加载速度 | SPA 单页，静态资源 CDN |

---

## 6. 约束与边界

| 约束 | 说明 |
|------|------|
| 不可修改题目 | 题库导入后不支持编辑，只能删除重建 |
| 答题不可恢复 | 答题中途退出，进度不保留 |
| 无管理员面板 | 没有用户管理、题库审核功能 |
| SQLite 并发 | 默认不支持并发写，适合单用户 |
| 无数据导出 | 不支持将题库或答题记录导出 |
| 章节精确匹配 | 背题模式的章节筛选为精确匹配，不支持多选 |

## 7. 未来方向（已排除 / 待定）

以下功能明确不包含在当前版本内，列在这里供后续参考：

- 题目编辑（导入后修改题目内容或答案）
- 批量导出（导出题库或答题记录为文件）
- 社交功能（分享成绩、排行榜）
- 管理员面板（用户管理、题库审核）
- 数据库迁移（SQLite → PostgreSQL）
- 图片/富文本题目
- 刷题计划与提醒
- 随机练习出题数量记忆（当前每次都要重新选择）
