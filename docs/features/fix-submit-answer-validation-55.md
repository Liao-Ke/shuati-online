# 修复 submit_answer 答案选项校验（issue #55）

## 背景

`POST /api/exam/{exam_id}/answer` 原先只校验题目是否属于当前练习，未校验提交答案是否属于题目允许的选项范围，导致选择题、多选题或判断题可以保存不存在的答案值。

## 修改范围

- 选择题：非空答案必须是字符串，且必须属于当前题目选项标签。
- 判断题：非空答案只能是 `对` 或 `错`。
- 多选题：非空答案必须是非空列表，不允许重复标签，且每个标签必须属于当前题目选项。
- 保留 `user_answer: null` 的兼容行为，用于跳过或未作答场景。

## 验证

- 新增集成测试覆盖非法选择题选项、选择题列表答案、非法判断题答案、多选重复/越界答案和空答案兼容行为。
- 本地执行 `ruff check --no-cache routers/exam.py test_integration.py`。
- 本地执行 Python AST 语法检查。
