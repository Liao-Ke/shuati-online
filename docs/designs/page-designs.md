# 前端页面设计

## 1. 登录页 `#/login`

### 布局
- 全屏居中布局（flexbox）
- 背景：`#EFF6FF`
- 居中白色卡片（`max-width: 400px`）

### 内容
```
┌──────────────────────┐
│       Logo           │
│   刷题在线           │
│                      │
│  用户名: [    ]      │
│  密码:   [    ]      │
│                      │
│  [    登 录    ]     │
│                      │
│  没有账号？去注册    │
└──────────────────────┘
```

### 交互
- 提交按钮全宽 Primary
- 提交中按钮显示 loading 状态
- 错误提示在表单上方（红色卡片）
- 成功跳转到 `#/dashboard`

```

│  点击下载示例 JSON 格式                    │
├────────────────────────────────────────────┤
│                                            │
│  ┌────────────────────┐  ┌──────────────┐ │
│  │ 数据结构基础        │  │ 算法入门     │ │
│  │ 120 题             │  │ 80 题        │ │
│  │ 2026-05-13 更新    │  │ 2026-05-10   │ │
│  │ [详情→] [删除]     │  │ [详情→] [删除]│ │
│  └────────────────────┘  └──────────────┘ │
│  ┌────────────────────┐                    │
│  │ 计算机网络         │                    │
│  │ 100 题             │                    │
│  │ 2026-05-08 更新    │                    │
│  │ [详情→] [删除]     │                    │
│  └────────────────────┘                    │
└────────────────────────────────────────────┘
```

### 导入弹窗
- 模态框：选择 JSON 文件 + 预览题库名称和题数
- 点击"确认导入"后显示 loading
- 成功后刷新列表，失败显示错误信息

### 示例 JSON
```json
{
  "title": "示例题库",
  "description": "这是一个示例题库",
  "questions": [
    {
      "type": "choice",
      "chapter": "第一章 基础",
      "content": "中国的首都是？",
      "options": ["A. 上海", "B. 北京", "C. 广州", "D. 深圳"],
      "answer": "B",
      "analysis": "北京是中国的首都。"
    },
    {
      "type": "fill",
      "content": "中国的首都是____。",
      "answer": "北京"
    },
    {
      "type": "fill",
      "content": "中国的四大发明是____、____、____和____。",
      "answer": ["造纸术", "印刷术", "火药", "指南针"]
    },
    {
      "type": "judge",
      "content": "长江是中国最长的河流。",
      "answer": "对"
    }
  ]
}
```

### 删除确认
- 模态框："确定删除题库「{标题}」吗？该操作不可恢复。"
- 删除按钮 Danger 变体

## 错误状态

- API 请求失败：页面内 Toast 或 Alert 提示 "加载失败，请重试"
- 表单提交失败：表单上方红色 Alert 显示具体错误
- 404：简单的 "页面未找到" + 返回首页按钮
